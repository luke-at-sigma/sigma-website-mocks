How dashboards work today

“Reports outlive their usefulness and nobody cleans them up”

How dashboards work today
  • —Sift through reports that nobody has cleaned up
  • —Read numbers that went stale on the last batch cycle
  • —File a ticket for every drill-down the business needs
How dashboards work in Sigma
  • ✓Query the warehouse live, so every open shows current numbers
  • ✓Drill from a flagged metric to the row that explains it
  • ✓Serve each audience a saved view instead of a new report

3 steps to a live dashboard

1
Connect the warehouse

Sigma queries your existing models and views live, so no extract needs a refresh schedule.

2
Build in a workbook

Analysts use spreadsheet formulas, SQL, and Python in one workbook, under warehouse permissions.

3
Publish the drill path

Business teams follow the path to the row themselves, so the request queue stops growing.

Built for the analytics team

Live query, no extracts

Sigma queries the warehouse when someone opens a workbook, so the number on screen is the number in the source. Filters push down, so scans stay narrow as more people use it.

  • ✓Query existing models and views with no rebuild

Questions from BI teams

Is Sigma just another BI platform?+
No. Sigma covers dashboards and BI, and the same workbook can collect an input and route an approval. Teams build AI Apps on that governed data, write changes back to the warehouse, and deploy Sigma Agents that take the next step.
Can business users drill down without breaking governance?+
Yes. Viewers follow the drill paths you publish and can pivot, filter, and add calculations on their own copy of the view. Row-level security from the warehouse applies to every query they run, so nobody sees a row their warehouse role blocks. The shared data model only changes when you change it.
What if AI answers contradict our dashboard?+
Point the AI at the same governed data the dashboard uses. Sigma has no model of its own, so you connect your own provider or call warehouse-native LLMs, and every call runs under existing permissions. When someone disputes a number, you can trace the query and the role behind it.
Which warehouses does Sigma query live?+
Sigma runs live on Databricks and Snowflake, and others like Amazon Redshift and BigQuery. Queries hit your tables and views with no extract, and filters push down to the warehouse. The list is not exhaustive, so check the Help Center for the current set of connections.
