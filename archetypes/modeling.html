How modeling works today

“Business users spend a day a week maintaining spreadsheets that pull from the warehouse”

How modeling works today
  • —Rebuild the model by hand every time an input changes
  • —Email the file around and lose track of which version is live
  • —Quote from a stale cost model and leak margin on every win
How modeling works in Sigma
  • ✓Type new assumptions into Input Tables and watch every row recalculate
  • ✓Compare 2 scenarios side by side on the same live data
  • ✓Lock the approved version and keep a row-level audit trail

Build a model in 3 steps

1
Set the assumptions

Set rate bands and driver weights in an Input Table. Every value lands in the governed warehouse.

2
Compare scenarios

Duplicate the inputs, change 3 drivers, and see both versions on one chart in seconds.

3
Lock and publish

Approve the version, then share the model as an app. Audit history shows who changed which input.

Built for real modeling depth

250+ functions in one workbook

Sigma keeps the formula freedom people expect from a spreadsheet, with 250+ functions and lookups on live tables. Custom SQL and Python run in the same workbook, so the logic stays together.

  • ✓Write formulas, SQL, and Python against the same live tables
  • ✓Query the warehouse live so no result rides on a stale extract
  • ✓Prototype in a sheet, then ship the same logic as an app

Common modeling questions

How is modeling in Sigma different from a spreadsheet?+
The formulas work the way you expect, and the data stays in the warehouse. You get 250+ spreadsheet functions, lookups, and window functions against live tables instead of a copied extract. Every input you type lands in an Input Table row under warehouse permissions. Nobody has to email the file to see the current version.
Can business users change assumptions without breaking the model?+
Yes. Assumptions live in Input Tables, so a manager can change a rate band or a driver weight in the cell itself. The calculation reruns on live data, and the formula layer stays locked to whoever owns it. Approvals freeze a version, and audit history shows every edit with a user and a timestamp.
Which AI model does Sigma use for modeling?+
Sigma has no model of its own. You configure your own LLM provider or invoke a warehouse-native model, so AI calls run inside the stack you already govern and Sigma logs every call.
How long does it take to build a model?+
Most teams get a first working model in hours. One customer prototyped in about three hours after budgeting two to three weeks. Start from an App Template, or copy a library app and point it at your own tables. The time you save compounds, because the next version does not start over.
