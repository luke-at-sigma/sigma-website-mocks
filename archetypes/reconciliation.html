Questions finance teams ask

Which warehouses can Sigma write back to?+
Input Tables write back to Databricks and Snowflake, and others like BigQuery and Amazon Redshift. Sigma writes each edit to a designated write schema through an append-only log, so Sigma never modifies production tables. Check the Help Center for the current connection list, since support keeps expanding.
Do we have to move data out of the warehouse?+
No. Sigma queries the warehouse live, so a reconciliation runs against the same rows your feeds just landed. There are no extracts to schedule and nothing to refresh before the close. Filters and joins push down, so the match reflects the current state every time someone opens the workbook.
How does Sigma handle AI in reconciliation?+
Sigma has no model of its own. You configure your own LLM provider or invoke a warehouse-native model, and Sigma logs every call alongside the query history. Sigma Agents can watch a reconciliation, flag balances outside tolerance, and summarize what moved.
Can finance edit numbers without breaking governance?+
Yes, within the permissions the warehouse already grants. An analyst types an adjustment or a comment into an Input Table, and Sigma stores it as a tagged row-level insert with user identity and timestamp. Row-level security still applies, so a contributor edits only what their role allows. Audit history keeps the full record.
